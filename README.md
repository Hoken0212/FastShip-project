# 🚀 FastShip - Last-Mile Delivery Management System

**FastShip** is the management system last-mile delivery, help connect to Admin, Delivery person and Clients in real-time.

![Project Status](https://img.shields.io/badge/Status-In_Development-yellow)
![License](https://img.shields.io/badge/License-MIT-blue)

## 🌟 Tính năng chính (Key Features)

- **Web Admin Dashboard:** Coordinate orders, manage delivery person, tracking dashboard
- **Mobile Driver App:** Take orders, update order status (already taken, currently delivering, success), view route 
- **Real-time Tracking:** Clients tracking shipper position on map at real-time.
- **Proof of Delivery:** Take photo when delivery success.

## 🛠 Công nghệ sử dụng (Tech Stack)

### Backend (Server)
- **Runtime:** Node.js
- **Database:** PostgreSQL (with PostGIS for geo-location)
- **Framework:** Express/NestJS (Planned)
- **Real-time:** Socket.io

### Frontend (Web Admin)
- **Framework:** ReactJS / VueJS
- **UI Library:** Ant Design / Tailwind CSS
- **Maps:** Mapbox GL JS / Leaflet

### Mobile (Shipper App)
- **Framework:** Flutter / React Native
